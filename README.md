# audit-perf

Audit de performance et de conformité pour sites de TPE/PME françaises.
100 % local, aucun service tiers, aucune clé API requise.

L'outil prend une liste d'entreprises, mesure leurs sites, et produit deux
choses : un tableau trié du pire au meilleur, et un rapport HTML par site qui
traduit chaque problème technique en conséquence commerciale compréhensible
par un gérant de PME.
